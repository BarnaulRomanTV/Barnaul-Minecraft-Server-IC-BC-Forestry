## ⚠️ Важное предупреждение по подключению

Сервер **недоступен из интернета** по IP `192.168.10.228` — это локальный адрес вашей сети.  
Подключиться могут **только устройства в одной Wi‑Fi/LAN‑сети** с сервером.

---

## Как подключиться (только для локальной сети)

1. Убедитесь, что ваш компьютер и сервер находятся в одной локальной сети (подключены к одному роутеру).
2. Откройте Minecraft Java Edition.
3. Нажмите «Сетевая игра» → «По адресу».
4. Введите: `katherine-lineage.tun.ply.gg:25565`
5. Нажмите «Подключиться».

> Если вы видите ошибку «Не удалось подключиться к серверу», проверьте, запущен ли сам сервер и не блокирует ли брандмауэр Windows входящие соединения.

## Если хотите открыть сервер для игроков из интернета

Есть три рабочих способа:

1. **Playit.gg** — самый простой вариант для Minecraft. Даёт постоянный домен, не требует настройки роутера.
2. **ngrok** — быстрый тест. Генерирует временный домен, подходит для проверки.
3. **Проброс портов (Port Forwarding)** на роутере — если у вас «белый» IP от провайдера. Нужно открыть порт `25565` (TCP/UDP) на адрес сервера `192.168.10.228`.

После настройки внешнего доступа замените в инструкции выше локальный IP на внешний домен/IP.
