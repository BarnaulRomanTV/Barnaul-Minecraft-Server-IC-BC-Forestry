## Как подключиться к серверу

Сервер доступен по адресу:

- **IP:** `ВАШ_ВНЕШНИЙ_IP_ИЛИ_ДОМЕН:25565`  
  (если используете туннель — укажите ссылку вида `play.playit.gg` или аналогичную)
- **Порт:** `25565` (указан по умолчанию, вводить отдельно не нужно)

### Инструкция для игроков

1. Откройте Minecraft Java Edition.
2. Нажмите «Сетевая игра» → «По адресу».
3. Введите: `ВАШ_ВНЕШНИЙ_IP_ИЛИ_ДОМЕН:25565`
4. Нажмите «Подключиться».
